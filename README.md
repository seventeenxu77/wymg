# 藏金匿影 / DEEP SEEK

一款本地双人非对称对抗游戏：怪物在宅邸中藏匿珍藏，盗贼则借助噪音、隐身和道具搜刮财物并设法撤离。

本项目由 Web 原型迁移至 Godot 4.7。当前版本使用 3D 房间与透视摄像机呈现 2.5D 纸片美术效果，不依赖浏览器、React 或 Node.js。

## 核心玩法

- 一场比赛共 4 局，每局最长 8 分钟。
- 奇数局玩家 A 是怪物、玩家 B 是盗贼；偶数局双方交换身份。
- 怪物先将三件专属藏品分别放入家具，然后追踪并攻击盗贼。
- 盗贼撞毁家具、搜集财物并撤离；未带出宅邸的财物不会计入收益。
- 盗贼停止移动后会立即从怪物视野中隐藏，移动、撞击和主动发声会暴露线索。
- 双方只有处于同一房间时才能直接看见彼此，各自拥有独立摄像机与会随视角旋转的小地图。
- 每局结束后进入双人商店。购买的道具先进入仓库，再由玩家放入最多 3 格的装备栏；未消耗道具可在后续局继承。
- 四局结束后按双方累计价值与金币结算胜者。

## 运行项目

需要 Godot `4.7.stable`。

1. 使用 Godot 4.7 导入本目录下的 `project.godot`。
2. 打开项目后按 `F5` 运行主场景。

也可以在 Windows 上双击 `run_game.bat`。

## 玩家操作

键位绑定到玩家，而不是绑定到角色。双方交换身份后仍使用各自原来的键位。

### 玩家 A（左侧）

| 功能 | 键位 |
| --- | --- |
| 移动 | `W / A / S / D` |
| 视角逆时针 / 顺时针旋转 45° | `Q / E` |
| 冲撞家具 | `G` |
| 拾取物品 / 打开交互 | `R` |
| 上一个 / 下一个道具 | `Z / X` |
| 使用所选道具 | `F` |
| 主动发声 | `B` |
| 怪物横扫攻击 | `空格` |
| 盗贼使用治疗药丸 | `C` |
| 盗贼在入口撤离 | `V` |
| 怪物提前结束藏宝 | `H` |
| 按住放大小地图 | `Tab` |
| 打开帮助 | `F1` |

### 玩家 B（右侧）

| 功能 | 键位 |
| --- | --- |
| 移动 | `方向键` |
| 视角逆时针 / 顺时针旋转 45° | `小键盘 7 / 9` |
| 冲撞家具 | `小键盘 0` |
| 拾取物品 / 打开交互 | `小键盘 1` |
| 上一个 / 下一个道具 | `小键盘 4 / 6` |

| 怪物横扫攻击 / 盗贼使用药丸 | `小键盘 2` |

| 按住放大小地图 | `小键盘 8` |

### 通用操作

- `Esc`：关闭当前面板；没有其他面板时打开暂停菜单。
- `F2`：重新生成宅邸。
- `` ` `` 或 `~`：打开 GM 控制台。
- 移动方向会根据各自摄像机的旋转自动换算，两个窗口的视角与键位互不干扰。

### 家具面板

只有当前怪物操作家具藏品面板：

- 玩家 A 是怪物时：`A / D` 左右选择，`R` 放入或取出。
- 玩家 B 是怪物时：`← / →` 左右选择，`小键盘 1` 放入或取出。
- `Esc`：关闭面板。

### 局间商店

商店分为商品、仓库和装备栏三列。购买后道具只会进入仓库，需要再次操作才能装备。

| 玩家 | 上下选择 | 左右切列 | 购买 / 装备 / 卸下 | 准备 |
| --- | --- | --- | --- | --- |
| A | `W / S` | `A / D` | `R` | `H` |
| B | `↑ / ↓` | `← / →` | `小键盘 1` | `小键盘 5` |

## 藏品与财物

| 物品 | 价值 | 说明 |
| --- | ---: | --- |
| 古钱币 | 2 | 宅邸内随机出现的野生藏品 |
| 银制烛台 | 4 | 怪物专属藏品 |
| 祖母绿胸针 | 6 | 怪物专属藏品 |
| 怪物之心 | 10 | 怪物专属藏品 |
| 旧怀表、银汤匙、铜制烟盒、珍珠纽扣 | 1 | 家具内概率出现的小财物 |
| 治疗药丸 | — | 固定刷新在地面，由盗贼拾取并恢复生命 |

盗贼损毁家具所需耐久由家具本身耐久与内部藏品价值共同决定；价值越高，家具越难被撞毁。怪物只需一次冲撞即可打开家具。

## 商店道具

| 英文 ID | 名称 | 价格 | 效果 |
| --- | --- | ---: | --- |
| `adrenaline` | 肾上腺素 | 2 | 速度翻倍 6 秒，随后以半速疲劳 3 秒 |
| `alarm` | 警报器 | 2 | 只能藏入附近的完好家具；家具被撞开后全图鸣响 5 秒 |
| `trap` | 捕兽夹 | 3 | 双方都会踩中；需左右交替按键 20 次挣脱，之后可以回收 |
| `decoy` | 替身玩偶 | 3 | 本体向前位移，替身向反方向奔跑 10 秒 |
| `phonograph` | 留声机 | 3 | 放置后再次靠近启动，延迟播放持续 10 秒的撞击噪音 |
| `spring_glove` | 弹簧拳套 | 4 | 短距离击退敌人并眩晕 1 秒，一次性使用 |
| `detector` | 藏品探测器 | 5 | 让同房间内含藏品的家具周期抖动；总电量 54 秒，可随时关闭 |
| `robot` | 发条巡夜偶 | 5 | 以玩家半速在召唤点九宫格巡逻，发现敌人后报警；再次使用可与其换位 |
| `teleporter` | 传送器 | 8 | 仅盗贼可用；持续轰鸣 5 秒后携带全部藏品直接撤离 |

巡夜偶被敌人撞击后会停机 10 秒，停机期间不能报警或换位；恢复后继续巡逻。

## 教程

教程独立于正式比赛，左右两名玩家可以同时选择并进行怪物或盗贼教学，彼此的输入与面板不会互相锁定。

- 玩家 A 按 `T`、玩家 B 按 `小键盘 -`，可随时退出各自当前教程并清理教程资源。
- 角色脚下会演示当前目标键位，下方闪烁提示框会显示需要完成的操作。
- 双方均完成或退出教程后，可选择开始新比赛或返回主菜单。

## GM 控制台

按 `` ` `` 或 `~` 打开控制台，输入 `help` 可在游戏内查看完整帮助。命令中的 `A / B` 始终代表玩家，不会因每局交换角色而改变。

| 命令 | 作用 |
| --- | --- |
| `help` | 显示命令和所有可用道具 ID |
| `next` | 跳过当前阶段，或结束当前局进入商店 / 最终结算 |
| `gold A 50` | 调整玩家 A 的金币；可以改为 B，也支持负数 |
| `give A adrenaline` | 将指定道具发给玩家；对局中进入当前道具栏，其他阶段加入持有物品 |
| `add robot` | 直接给玩家 A 装备道具 |
| `add B robot` | 直接给玩家 B 装备道具 |
| `trans A` | 将玩家 B 移动到玩家 A 的实际位置 |
| `trans B` | 将玩家 A 移动到玩家 B 的实际位置 |
| `cooldown reset` | 重置当前怪物的攻击冷却 |
| `cooldown reset A` | 指定玩家为当前怪物时重置；也支持 `B` 或 `all` |
| `tutorial` | 打开双人教程选择界面 |
| `tutorial A thief` | 让玩家 A 开始盗贼教程；角色也可以写 `monster` |
| `tutorial next A` | 跳过玩家 A 当前教程步骤 |
| `tutorial reset A` | 重置玩家 A 的当前教程 |
| `tutorial stop` | 关闭教程、清理资源并重新开始正式比赛 |
| `pause` / `pause off` | 打开 / 关闭游戏内暂停菜单 |
| `menu` / `menu off` | 返回 / 关闭主菜单 |

## 导出 Windows 版本

项目已经包含 `Windows Desktop` 导出预设：

1. 在 Godot 中选择“项目 → 导出”。
2. 选择 `Windows Desktop`。
3. 点击“导出项目”。
4. 正式发布时不要勾选“导出并启用调试”。

默认会生成 `DEEP SEEK.exe`。PCK 资源已经嵌入主程序，因此这是免安装的独立可执行文件，玩家可直接双击运行。

`DEEP SEEK.console.exe` 是调试控制台启动器，正常发布时不需要提供。若需要传统安装包，可再使用 Inno Setup 或 NSIS 封装。

## 项目结构

```text
main.tscn
scripts/
  main.gd                     # 输入与总体流程协调
  systems/                    # 房间、角色、音频、回合、商店和道具规则
  presentation/game_hud.gd    # 双分屏 HUD、菜单、小地图和面板
  tutorial/                   # 双人独立教程
  world_25d.gd                # 3D 房间、纸片角色、透视摄像机和渲染同步
assets/
  25d/items/                  # 藏品、财物与道具的场景贴图
  ui/                         # HUD、菜单、教程和道具图标
tests/                        # Godot 无头回归测试
```

项目固定使用 60 Hz 物理逻辑帧，并启用物理插值，以减少透视跟随摄像机下的角色和场景抖动。
