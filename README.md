# 老宅窃影 — gamejam Godot 4.7 迁移版

这是 `web-whitebox` 的 Godot 4.7 原生 2.5D 迁移工程，不再依赖浏览器、React 或 Node.js。画面采用斜俯视正交摄像机、3D 房间结构与原创手绘纸片角色/家具。

## 启动

使用 Godot 4.7 打开本目录的 `project.godot`，然后按 `F6` 或 `F5` 运行。

也可以双击 `run_game.bat`。

## 操作

怪物：

- `WASD`：移动
- `G`：抓取或松开家具
- `F`：放置当前藏品
- `R`：切换藏品
- `空格`：扇形挥砍
- `T`：切换家具移动/旋转模式
- 旋转模式下使用 `A/D` 或 `Z/C` 旋转

盗贼：

- 方向键：移动
- 小键盘 `0`：抓取或松开家具
- 小键盘 `1`：搜查或拾取
- 小键盘 `2`：使用治疗药丸
- 小键盘 `3`：切换家具移动/旋转模式
- 小键盘 `4/6`：旋转家具
- 小键盘 `5`：在入口撤离
- 小键盘 `7/9`：右侧视角逆时针/顺时针旋转 45°

通用：

- `Q / E`：仅旋转左侧怪物视角 45°
- `H`：藏宝阶段提前结束
- `F2`：重新生成宅邸

移动方向会自动跟随各自视角旋转：左侧 `WASD` 只参考左侧摄像机，右侧方向键只参考右侧摄像机。

## 已迁移功能

- 6×6 随机连通房间
- 双正交摄像机的 2.5D 房间视图
- 原创手绘纸片角色、家具、藏品和药丸
- 立体墙体、地面、阴影与压暗环境光
- 双视角同屏与双方独立控制
- 藏宝、准备倒计时、实时搜查和结算阶段
- 三件不同价值的藏品、胜利门槛、药丸
- 家具连续移动、中心旋转、碰撞和永久拖动轨迹
- 基于帧时间的连续空间移动与无缝跨房间坐标
- 互动痕迹、噪音方向、房间距离限制
- 盗贼动态残影与怪物扇形攻击
- 带门位置的 6×6 小地图
