# DEEP SEEK — gamejam Godot 4.7 迁移版

这是 `web-whitebox` 的 Godot 4.7 原生 2.5D 迁移工程，不再依赖浏览器、React 或 Node.js。画面采用跟随角色的透视摄像机、3D 房间结构与原创手绘纸片角色/家具。

## 启动

使用 Godot 4.7 打开本目录的 `project.godot`，然后按 `F6` 或 `F5` 运行。

也可以双击 `run_game.bat`。

启动后首先进入主界面：

- 鼠标悬浮并点击物品，或使用 `A / D`、方向键选择
- `Enter / 空格`：确认
- 设置与退出确认页面中按 `Esc` 返回
- GM 控制台输入 `pause` 可打开游戏内退出菜单，输入 `menu` 可从对局或教程直接返回主界面
- GM 控制台输入 `trans A` 可把玩家 B 传送到玩家 A 的位置；`trans B` 则把玩家 A 传送到玩家 B 的位置。传送后双方强制互相可见，盗贼再次移动后恢复正常隐身规则
- GM 控制台输入 `cooldown reset` 可重置当前怪物的攻击冷却；所有命令和道具参数均使用英文 ID，例如 `add B adrenaline`

## 操作

怪物：

- `WASD`：移动
- `G`：沿当前朝向后撤蓄力并冲撞家具；怪物一击即可打开
- `空格`：横扫攻击；命中会令盗贼硬直，攻击冷却 10 秒
- 按住 `Tab`：临时放大左侧地图
- `F1`：打开或关闭左侧规则帮助

家具面板打开后：

- `A / D`：左右选择怪物藏品
- `R`：将选中藏品存入家具，或从家具中取出
- `Esc`：关闭家具面板并恢复移动

盗贼：

- 方向键：移动
- 小键盘 `0`：沿当前朝向后撤蓄力并冲撞家具，达到家具耐久后将其损毁
- 小键盘 `1`：拾取损毁家具掉出的财物或药丸
- 小键盘 `2`：使用治疗药丸
- 小键盘 `5`：在入口执行本局唯一一次撤离
- 小键盘 `7/9`：右侧视角逆时针/顺时针旋转 45°
- 按住小键盘 `8`：临时放大右侧地图
- 小键盘 `+`：打开或关闭右侧规则帮助

通用：

- `Q / E`：仅旋转左侧怪物视角 45°
- `B`（玩家 A）/小键盘 `*`（玩家 B）：角色主动发声；盗贼尖叫、怪物大笑，并产生持续 3 秒的位置噪音
- `H`：藏宝阶段提前结束
- `Esc`：关闭当前帮助/家具面板；没有其他面板时打开暂停菜单，可继续游戏或退出到主菜单
- `F2`：重新生成宅邸

藏品探测器拥有 54 秒总电量（原时长的三倍）；再次按使用键可随时关闭并保留剩余电量。

移动方向会自动跟随各自视角旋转：左侧 `WASD` 只参考左侧摄像机，右侧方向键只参考右侧摄像机。

教程中两侧输入互不锁定：左侧用 `T`、右侧用小键盘 `-` 随时退出当前教程并清理该侧资源。角色脚下会循环演示当前目标键位；下方闪烁目标框会明确提示撞击、拾取、商店和道具操作。双方都退出教学后会弹出共同确认窗口：选择“冲”开始全新的第一局，选择“先等等”返回主菜单，按空格确认当前选项。正式游戏四局全部结束后，只显示比赛胜者；选择“重新开始”或“返回到主菜单”，按空格确认。

## 已迁移功能

- 6×6 随机连通房间
- 双透视跟随摄像机的 2.5D 房间视图
- 原创手绘纸片角色、家具、藏品和药丸
- 新人物 PNG、黑色描边、家具阴影与待机/行走摆动
- 床、衣柜、书柜、木桶、木箱、花瓶六类家具
- 每个房间随机使用木地板或像素地板纹理，墙体使用美术纹理
- 立体墙体、地面、阴影与压暗环境光
- 双视角同屏与双方独立控制
- 纯双分屏界面、各自独立的小地图/帮助弹层和底部键位提示
- 藏宝、准备倒计时、实时搜查和结算阶段
- 三件不同价值的藏品、50% 家具小财物、胜利门槛和药丸
- 藏品价值翻倍，结算时 1 点价值兑换 1 金币
- 家具定向撞击动画、受击抖动、分级耐久、内容物掉落和损毁状态
- 怪物藏品/家具双面板，每件家具最多存放一件正式藏品
- 藏品家具按内部总价值呈现不同强度的左右晃动
- 携带价值与撤离价值分开结算，每局只允许撤离一次
- 基于帧时间的连续空间移动与无缝跨房间坐标
- 互动痕迹、噪音方向、房间距离限制
- 盗贼动态红色残影、受击后仰与屏幕红闪；怪物横扫攻击带命中硬直和 10 秒冷却
- 家具受撞高频抖动；捕兽夹触发后夹子弹跳、角色持续红闪剧烈挣扎并显示脚下闪烁按键
- 带门位置的 6×6 小地图，怪物可追踪自己已放置的藏品
