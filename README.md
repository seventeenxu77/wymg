# 老宅窃影 — gamejam Godot 4.7 迁移版

这是 `web-whitebox` 的 Godot 4.7 原生 2.5D 迁移工程，不再依赖浏览器、React 或 Node.js。画面采用跟随角色的透视摄像机、3D 房间结构与原创手绘纸片角色/家具。

## 启动

使用 Godot 4.7 打开本目录的 `project.godot`，然后按 `F6` 或 `F5` 运行。

也可以双击 `run_game.bat`。

## 操作

怪物：

- `WASD`：移动
- `G`：沿当前朝向后撤蓄力并冲撞家具；怪物一击即可打开
- `空格`：扇形挥砍

家具面板打开后：

- `W / S`：上下选择怪物藏品
- `R`：将选中藏品存入家具，或从家具中取出
- `Esc`：关闭家具面板并恢复移动

盗贼：

- 方向键：移动
- 小键盘 `0`：沿当前朝向后撤蓄力并冲撞家具，达到家具耐久后将其损毁
- 小键盘 `1`：拾取损毁家具掉出的财物或药丸
- 小键盘 `2`：使用治疗药丸
- 小键盘 `5`：在入口执行本局唯一一次撤离
- 小键盘 `7/9`：右侧视角逆时针/顺时针旋转 45°

通用：

- `Q / E`：仅旋转左侧怪物视角 45°
- `H`：藏宝阶段提前结束
- `F2`：重新生成宅邸

移动方向会自动跟随各自视角旋转：左侧 `WASD` 只参考左侧摄像机，右侧方向键只参考右侧摄像机。

## 已迁移功能

- 6×6 随机连通房间
- 双透视跟随摄像机的 2.5D 房间视图
- 原创手绘纸片角色、家具、藏品和药丸
- 立体墙体、地面、阴影与压暗环境光
- 双视角同屏与双方独立控制
- 藏宝、准备倒计时、实时搜查和结算阶段
- 三件不同价值的藏品、50% 家具小财物、胜利门槛和药丸
- 家具定向撞击动画、受击抖动、分级耐久、内容物掉落和损毁状态
- 怪物藏品/家具双面板，每件家具最多存放一件正式藏品
- 藏品家具按内部总价值呈现不同强度的左右晃动
- 携带价值与撤离价值分开结算，每局只允许撤离一次
- 基于帧时间的连续空间移动与无缝跨房间坐标
- 互动痕迹、噪音方向、房间距离限制
- 盗贼动态残影与怪物扇形攻击
- 带门位置的 6×6 小地图
