# 藏金匿影 / DEEP SEEK

一款本地双人非对称对抗游戏：怪物在宅邸中藏匿珍藏，盗贼则借助噪音、隐身和道具搜刮财物并设法撤离。

本项目由 Web 原型迁移至 Godot 4.7。当前版本使用 3D 房间与透视摄像机呈现 2.5D 纸片美术效果，不依赖浏览器、React 或 Node.js。

后续功能、已完成事项和当前优先级统一记录在 [TODO.md](TODO.md)。切换开发窗口或开始新任务时先查看该文件。

## 核心玩法

- 一场比赛共 4 局，每局最长 8 分钟。
- 奇数局玩家 A 是怪物、玩家 B 是盗贼；偶数局双方交换身份。
- 怪物先将三件专属藏品分别放入家具，然后追踪并攻击盗贼。
- 盗贼撞毁家具、搜集财物并撤离；未带出宅邸的财物不会计入收益。
- 盗贼停止移动后会立即从怪物视野中隐藏，移动、撞击和主动发声会暴露线索。
- 双方只有处于同一房间时才能直接看见彼此，各自拥有独立摄像机与会随视角旋转的小地图。
- 每局结束后进入双人商店。购买的道具先进入仓库，再由玩家放入最多 3 格的装备栏；未消耗道具可在后续局继承。
- 四局结束后按双方累计价值与金币结算胜者。

## 运行项目

需要 Godot `4.7.stable`。

1. 使用 Godot 4.7 导入本目录下的 `project.godot`。
2. 打开项目后按 `F5` 运行主场景。

也可以在 Windows 上双击 `run_game.bat`。

### 模式入口与联机大厅框架

主菜单的“开始比赛”现在会先进入模式选择：

- “经典本地双人”保留原有同键盘、双分屏与四局比赛。
- “联机狩猎”进入独立网络大厅，支持创建/加入 ENet 房间、玩家槽、准备和房主开始。
- 联机开始后进入复用现有 2.5D 宅邸内容的单视角地图；客户端上传输入，服务器按原有房间、
  墙体和家具碰撞同步四名玩家的位置。
- “单人冒险”与“回合战棋”保留为后续模式入口。

在 Windows PowerShell 中运行 `.\dev\run_1v3.ps1`，可以启动一个无窗口服务器和四个
自动连接到 `127.0.0.1` 的客户端窗口。运行 `.\dev\stop_1v3.ps1` 可关闭这些测试实例。
追加 `-AutoMove` 可以让四个测试客户端向不同方向自动移动，用于快速检查同步：

```powershell
.\dev\run_1v3.ps1 -AutoMove
```

追加 `-SkipHide` 会自动结束藏宝但保留四个窗口的手动输入，适合快速验证潜行、噪音和后续战斗：

```powershell
.\dev\run_1v3.ps1 -SkipHide
```

追加 `-CombatTest` 会跳过藏宝，并把怪物与三名盗贼放到入口房的近距离阵型，方便直接验证攻击、
倒地和救援：

```powershell
.\dev\run_1v3.ps1 -CombatTest
```

追加 `-ToolTest` 会使用同房近距离出生点，并把全部九种联机道具分配给四个槽位：

```powershell
.\dev\run_1v3.ps1 -ToolTest
```

当前联机对局已经迁移随机宅邸、家具、角色纸片、房间光照、单视角摄像机、小地图以及
“藏宝—准备—狩猎”阶段。怪物可在藏宝阶段面向家具按 `G` 打开面板，用 `A / D` 选择三件
专属藏品并按 `R` 存取，按 `Esc` 关闭面板，或按 `H` 提前开始狩猎。盗贼在狩猎阶段面向家具
按 `G` 可按服务器判定的耐久逐次破坏家具；打开、损伤、内容物和掉落会同步给全部客户端。
盗贼靠近掉落的财物或药丸后按 `R` 拾取，每名盗贼分别记录携带数量与价值；回到入口按 `V`
可独立撤离，撤离角色停止行动但不会结束其他人的比赛。职业、技能和最终胜负规则仍待实现。

狩猎阶段中，怪物按 `空格` 发动前方横扫，攻击、冷却和命中全部由服务器裁定。盗贼有 2 点生命；
生命归零后倒地并停止移动、交互、拾取和撤离。其他盗贼可在其附近按住 `F` 2.5 秒完成救援，
松键、离开范围、受击或倒地会中断进度；救援后恢复 1 点生命并获得短暂无敌。本阶段不会因倒地
或全部盗贼失去行动能力而结束比赛，淘汰与胜负规则留待后续讨论。

联机装备栏已支持九种本地道具。使用 `Z / X` 切换装备，按 `C` 使用或部署。肾上腺素、
替身玩偶、留声机和捕兽夹保留原有规则；探测器按开启时间消耗电量并标记当前房间家具；
警报器安装进空家具后会在家具被打开或破坏时发出全局警报；盗贼传送器轰鸣 5 秒后携带全部
财物撤离，受击、陷阱和拳套会中断蓄力；弹簧拳套击退并短暂眩晕前方敌人；发条巡夜偶在
召唤点九宫格巡逻、发现敌人报警，被敌方撞击后停机 10 秒，正常工作时可与主人换位。
这些状态均由服务器裁定并通过紧凑快照或可靠事件同步。当前普通联机局只会在家具中自然生成
肾上腺素，其他道具暂由 `-ToolTest` 固定发放，等待联机商店与赛前装备配置迁移。

狩猎阶段中，每名盗贼停止移动约 `0.8` 秒后进入潜行；移动、撞击家具或拾取物品会更新其
暴露状态，但怪物视角不直接显示盗贼实体，而以本地版的红色移动残影表现踪迹。盗贼的小地图
保留队友标记。怪物脚步、家具撞击和拾取行为会产生服务器权威噪音；对方在两房间范围内会在
自己角色中心看到按屏幕左／右区分的匿名扩散波纹，小地图波纹仅作为辅助。

从大厅开始对局后，各窗口会先进入资源初始化页。客户端完成宅邸、角色和渲染帧预热后向服务器
确认；服务器收到当前全部玩家的确认才统一显示正式游戏画面并开始阶段计时。联机客户端只创建
自己阵营需要的一个 3D 视口，并复用地板、墙体、常用材质和纹理资源；经典双分屏仍保留双视口。

### 通用操作

- `Esc`：关闭当前面板；没有其他面板时打开暂停菜单。
- `F2`：重新生成宅邸。
- `` ` `` 或 `~`：打开 GM 控制台。
- 移动方向会根据各自摄像机的旋转自动换算，两个窗口的视角与键位互不干扰。

### 家具面板

只有当前怪物操作家具藏品面板：

- 玩家 A 是怪物时：`A / D` 左右选择，`R` 放入或取出。
- 玩家 B 是怪物时：`← / →` 左右选择，`小键盘 1` 放入或取出。
- `Esc`：关闭面板。

### 局间商店

商店分为商品、仓库和装备栏三列。购买后道具只会进入仓库，需要再次操作才能装备。

| 玩家 | 上下选择 | 左右切列 | 购买 / 装备 / 卸下 | 准备 |
| --- | --- | --- | --- | --- |
| A | `W / S` | `A / D` | `R` | `H` |
| B | `↑ / ↓` | `← / →` | `小键盘 1` | `小键盘 5` |

## 教程

教程独立于正式比赛，左右两名玩家可以同时选择并进行怪物或盗贼教学，彼此的输入与面板不会互相锁定。

- 玩家 A 按 `T`、玩家 B 按 `小键盘 -`，可随时退出各自当前教程并清理教程资源。
- 角色脚下会演示当前目标键位，下方闪烁提示框会显示需要完成的操作。
- 双方均完成或退出教程后，可选择开始新比赛或返回主菜单。

## GM 控制台

按 `` ` `` 或 `~` 打开控制台，输入 `help` 可在游戏内查看完整帮助。命令中的 `A / B` 始终代表玩家，不会因每局交换角色而改变。

| 命令 | 作用 |
| --- | --- |
| `help` | 显示命令和所有可用道具 ID |
| `next` | 跳过当前阶段，或结束当前局进入商店 / 最终结算 |
| `gold A 50` | 调整玩家 A 的金币；可以改为 B，也支持负数 |
| `give A adrenaline` | 将指定道具发给玩家；对局中进入当前道具栏，其他阶段加入持有物品 |
| `add robot` | 直接给玩家 A 装备道具 |
| `add B robot` | 直接给玩家 B 装备道具 |
| `trans A` | 将玩家 B 移动到玩家 A 的实际位置 |
| `trans B` | 将玩家 A 移动到玩家 B 的实际位置 |
| `cooldown reset` | 重置当前怪物的攻击冷却 |
| `cooldown reset A` | 指定玩家为当前怪物时重置；也支持 `B` 或 `all` |
| `tutorial` | 打开双人教程选择界面 |
| `tutorial A thief` | 让玩家 A 开始盗贼教程；角色也可以写 `monster` |
| `tutorial next A` | 跳过玩家 A 当前教程步骤 |
| `tutorial reset A` | 重置玩家 A 的当前教程 |
| `tutorial stop` | 关闭教程、清理资源并重新开始正式比赛 |
| `pause` / `pause off` | 打开 / 关闭游戏内暂停菜单 |
| `menu` / `menu off` | 返回 / 关闭主菜单 |

## 导出 Windows 版本

项目已经包含 `Windows Desktop` 导出预设：

1. 在 Godot 中选择“项目 → 导出”。
2. 选择 `Windows Desktop`。
3. 点击“导出项目”。
4. 正式发布时不要勾选“导出并启用调试”。

默认会生成 `DEEP SEEK.exe`。PCK 资源已经嵌入主程序，因此这是免安装的独立可执行文件，玩家可直接双击运行。

`DEEP SEEK.console.exe` 是调试控制台启动器，正常发布时不需要提供。若需要传统安装包，可再使用 Inno Setup 或 NSIS 封装。

## 项目结构

```text
main.tscn
scripts/
  main.gd                     # 输入与总体流程协调
  state/                      # 角色、状态效果、道具与装置的统一状态构造
  systems/                    # 房间、角色、音频、回合、商店和道具规则
  presentation/               # 双分屏 HUD、菜单、独立小地图渲染和面板
  tutorial/                   # 双人独立教程
  world_25d.gd                # 3D 房间、纸片角色、透视摄像机和渲染同步
assets/
  25d/items/                  # 藏品、财物与道具的场景贴图
  ui/                         # HUD、菜单、教程和道具图标
tests/                        # Godot 无头回归测试
```

项目固定使用 60 Hz 物理逻辑帧，并启用物理插值，以减少透视跟随摄像机下的角色和场景抖动。
